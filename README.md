# Python — Listas e Manipulação de Dados

Repositório dedicado aos exercícios práticos de Python, com foco na criação, consulta, inserção e remoção de elementos em listas.

## Conteúdos abordados

- Criação e inicialização de listas.
- Armazenamento e organização de strings em coleções.
- Utilização da função `len()` para contar elementos.
- Acesso a elementos por meio de índices.
- Exibição de informações no terminal com `print()`.
- Inserção de elementos com os métodos `append()` e `insert()`.
- Remoção de elementos com o método `remove()`.
- Utilização de quebras de linha e formatação de strings.

## Objetivo

Desenvolver habilidades fundamentais de manipulação de dados em Python, compreender o funcionamento das listas e aplicar operações básicas de organização e gerenciamento de informações.

## Tecnologia

- Python 3

Este repositório registra a prática dos conceitos de listas e estruturas de dados básicas, contribuindo para o desenvolvimento da lógica de programação.
